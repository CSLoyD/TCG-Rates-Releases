# TCG Rates -- Releases

Published builds of the TCG Rates WooCommerce plugin.

Stores running the plugin read `update.json` from this repo and offer
the latest release through the normal WordPress plugin updater, so
there is usually nothing to do here by hand.

To install or update manually, download `tcg-rates.zip` from the
latest release and upload it in **WP Admin -> Plugins -> Add New ->
Upload Plugin**.
